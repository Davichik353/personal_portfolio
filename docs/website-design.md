# Portfolio visual reference lock

User-selected source: [Miranda on Refero](https://styles.refero.design/style/3f6e3076-e77f-487e-b212-3b5946a34e87), inspected as the actual public page and full embedded DESIGN.md on 2026-11-16. Source site: https://www.niccolomiranda.com. This source supersedes the earlier white/yellow studio exploration.

Preserve the newspaper structure, parchment canvas, compressed oversize serif masthead, sharp media frames, thin ink rules, serif reading text, and dense but readable editorial rhythm. The result presents Davlatbek's real development work and client contact details.

| Decision | Source rule and role | Adaptation |
| --- | --- | --- |

| Ink #1d1d1b and charcoal #69645f | Type, rules, banners; secondary type | High-contrast content and restrained metadata hierarchy. |
| Large DAVICHIK353 masthead | Full-width ink banner, tightly compressed display serif | The real public username stays legible in every language; scales to the viewport without overflow. |

| Ember #c03f13 | Decorative stamps/badges only | Available only to explicit editorial stamp classes; no orange canvas, body text or focus chrome. No false NEW claims. |
| Real animations and original avatar | Image-led work spread and identity artwork | Authentic project screenshots and original app illustrations retain their source colors, as the Miranda reference retains art-directed color imagery. The original Pac-Man is printed in ink. No invented app screenshots. |

Reject cool-white/gray product chrome, gradients, glass, generic rounded cards, sans-serif headings, decorative single-word font swaps, broad shadows, and unverified project claims. The existing avatar's yellow is converted to black ink to avoid introducing an extra UI accent.

Local font assets include upstream SIL Open Font License files. All localization remains real selectable DOM text; responsive rules use logical inline properties for automatic RTL translations.

Final opening composition adds the source-signature image–type–image featured strip before the masthead. Final selected case set is VIVID ADS, AI Code Mentor, KiroPiko and Bubble Tea Shop. KiroPiko uses the actual first sprite-sheet pose; Bubble Tea uses a contained original product illustration. Four work entries form a 2×2 spread.
